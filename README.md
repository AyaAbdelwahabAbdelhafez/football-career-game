# مسيرة اللاعب الاحترافية — Football Career Prototype (v2)

نموذج ألعاب تفاعلي (Web App) لمحاكاة مسيرة لاعب كرة قدم كاملة — من الأكاديمية إلى النجومية العالمية ثم الاعتزال.
مبني بـ **React + Vite** بهيكلية معيارية (Modular) قابلة للتوسّع بسهولة.

## الميزات المُنفَّذة في هذا الإصدار

- 🎮 إنشاء لاعب مخصص أو الانطلاق من لاعب مشهور (نقطة بداية خيالية فقط).
- 🏟️ أكثر من 30 نادياً موزّعة على 6 دوريات محلية عبر دول مختلفة، مع ترقٍّ حقيقي بين المستويات.
- ⚽ محاكاة مباراة 2D بمنظور علوي (SVG) مع أحداث حية وتعليق نصي.
- 🔁 عروض انتقال، تفاوض، وتاريخ أندية كامل (Timeline).
- 🏆 ترتيب دوري حي (يُحدَّث تلقائياً بعد كل مباراة) + كأس محلي بنظام إقصائي.
- 🇺🇳 منتخب وطني: استدعاء، مباريات دولية، بطولات قارية/عالمية.
- 🥇 جوائز فردية نهاية كل موسم (الكرة الذهبية، الحذاء الذهبي، أفضل لاعب شاب) بمقارنة مع منافسين محاكاة.
- 💪 تدريب متقدم: فني / جيم / تغذية / راحة — مع نظام إصابات متدرّج (طفيفة/متوسطة/خطيرة) يمنع اللعب حتى التعافي.
- 💰 نظام مالي: راتب دوري، عقود رعاية تجارية، استثمار الأموال، ومقتنيات فاخرة ترفع المعنويات والسمعة.
- 📰 أخبار داخل اللعبة + شبكة تواصل اجتماعي افتراضية (متابعون ومنشورات تفاعلية).
- 🎤 مؤتمرات صحفية سياقية (بعد فوز/خسارة/إصابة/جائزة/شائعات انتقال) تؤثر على العلاقات.
- 👋 اعتزال مع اختيار مسار حياة لاحق (تدريب، تحليل رياضي، أكاديمية، تقاعد).
- 💾 حفظ تلقائي محلي (localStorage) — استئناف المسيرة من حيث توقفت.

## المتطلبات
- [Node.js](https://nodejs.org) نسخة 18 أو أحدث (يشمل npm).

## التشغيل على جهازك
```bash
npm install
npm run dev
```
افتح الرابط الذي يظهر في الطرفية (عادة `http://localhost:5173`).

## بناء نسخة نهائية للنشر
```bash
npm run build
npm run preview
```
ينشئ هذا مجلد `dist/` جاهز للنشر على أي استضافة ثابتة (Netlify, Vercel, GitHub Pages...) أو تغليفه كتطبيق موبايل عبر Capacitor/Tauri لاحقاً.

## هيكل المشروع (معياري / Modular)
```
src/
├── main.jsx                  نقطة تشغيل React + Error Boundary
├── App.jsx                   المنسّق الرئيسي: الحالة العامة وربط الشاشات بالأنظمة
├── styles.css                كل التنسيقات البصرية للعبة
├── data/
│   ├── clubs.js               الأندية والدوريات (أضف نادياً أو دورياً جديداً هنا)
│   └── content.js              المراكز، اللاعبون الحقيقيون، أسئلة الصحافة، الرعاة، المقتنيات، قوالب الأخبار
├── utils/
│   └── helpers.js               أدوات عامة (عشوائية، حفظ محلي، تنسيق الأرقام)
├── systems/                    منطق اللعبة الصِرف (بلا واجهة) — كل نظام في ملفه:
│   ├── playerFactory.js          إنشاء لاعب جديد بكل حقول الحالة
│   ├── finance.js                 الراتب، الرعاية، الاستثمار، المشتريات
│   ├── training.js                 التدريب والإصابات
│   ├── competitions.js              ترتيب الدوري ومحاكاة الكأس
│   ├── nationalTeam.js               الاستدعاء، المباريات الدولية، البطولات
│   ├── awards.js                      حفل الجوائز الفردية
│   └── news.js                         الأخبار وشبكة التواصل الاجتماعي
└── components/
    ├── shared/Shared.jsx           عناصر مشتركة: OvrRing, TopBar, BottomNav
    └── screens/                    كل شاشة في ملف مستقل (Home, Matches, Match,
                                      Club, Transfers, More + شاشاته الفرعية،
                                      Press, Retire, Settings, AwardsCeremony...)
```

## كيف تضيف محتوى جديداً؟

**نادٍ جديد:** أضف كائناً إلى مصفوفة `CLUBS` في `src/data/clubs.js` (name, league, tier, strength, color, stadium, founded, capacity).

**دوري جديد:** أضف كائناً إلى `LEAGUES` في نفس الملف بمعرّف فريد `id`، ثم اربط الأندية به عبر حقل `league`.

**لاعب حقيقي (نقطة انطلاق):** أضف كائناً إلى `REAL_PLAYERS` في `src/data/content.js`.

**سؤال صحفي جديد:** أضفه إلى بنك مناسب داخل `PRESS_BANKS` في `src/data/content.js` (general / post_win / post_loss / post_injury / transfer_rumors / post_award).

**عنصر رعاية أو مقتنى فاخر:** عدّل `SPONSOR_TEMPLATES` أو `LUXURY_ITEMS` في `src/data/content.js`.

**بطولة أو نظام جديد بالكامل:** أضف ملفاً جديداً تحت `src/systems/` بدوال صِرفة (تأخذ اللاعب وتُرجع نسخة محدَّثة منه)، ثم استدعِه من `App.jsx` داخل `handleMatchFinish` أو `advanceSeasonMaybe` حسب توقيته المناسب، وأضف شاشة عرض له تحت `src/components/screens/` وسجّلها في `MoreScreen.jsx`.

## ملاحظة مهمة
الأسماء الحقيقية المتاحة كنقطة انطلاق هي مجرد قصة خيالية داخل اللعبة — كل الأحداث بعدها (المباريات، الانتقالات، التصريحات، النتائج) من نسج المحاكاة العشوائية وليست وقائع حقيقية.
